# Antigravity DataFlow - Alteryx Compatibility

Version 2.1.0. Generated by `scripts/generate_compatibility.py` - do not edit by hand.

DataFlow reads Alteryx `.yxmd` workflows and runs equivalents of the core tools. It is **not** Alteryx: this page says what is covered, how well it is checked, and where results can differ.

## How to read the columns

| Column | Meaning |
|---|---|
| Import | The tool is converted when you open a `.yxmd` file. |
| Fixtures | Bundled real Alteryx workflows that contain the tool (all are parsed in the test suite). |
| Tests | Test files that run the tool by name. |
| Golden | Expected-output cases that check the tool's results. **derived** = worked out from documented Alteryx behavior; **verified** = compared with a real Alteryx run. |

## DataFlow-only tools

These have no Alteryx equivalent in the importer: **LLM Process**, **Schema Fit**, **LLM Override**. **Unsupported Tool** is the placeholder the importer creates for any Alteryx tool it cannot convert.

## Alteryx tools that are not supported

Opening a workflow that uses any other tool (for example spatial tools such as Create Points or Find Nearest, predictive, reporting, in-database or macro-based tools) replaces it with an **Unsupported Tool** placeholder. The placeholder passes its input through unchanged, so downstream results can differ from Alteryx. After every import DataFlow lists the placeholders in a warning; review each one before relying on the output.

Bundled fixtures that import with placeholders: `challenge_15_atcodedog05_Solution.yxmd`.

## What is not claimed

- Results are not guaranteed to match Alteryx for every input. Golden cases marked **derived** have not been compared with a real Alteryx run.
- Performance, memory behavior and the exact text of error messages differ.
- To check your own workflow, run it in both tools on a sample and compare the outputs.
