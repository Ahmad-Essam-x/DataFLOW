## In / Out

### Input Data

Reads a CSV, TSV, Excel (.xlsx/.xls) or Parquet file, a wildcard set of files, or a database query.

- **Inputs:** none
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| File path | The file to read. Relative names are looked up in your data folder. |
| Delimiter / quote / encoding | How to parse delimited text. Header detection is automatic. |
| Sheet | For Excel: which sheet to read, or all sheets. |
| Bad lines | What to do with malformed rows: stop with an error, or skip them. |

**Notes:** Excel files are read with the pandas engine, so very large workbooks take longer than CSV.

### Output Data

Writes the incoming records to a CSV or Excel file in your outputs folder.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| File name / format | CSV or Excel. |
| Write mode | Overwrite, or append where supported. |
| Delimiter, encoding, quoting, line ending | CSV formatting options. |

**Notes:** Written files appear under Data > outputs and can be downloaded from the results panel.

### Text Input

Creates a small table by typing or pasting values, for lookups and test data.

- **Inputs:** none
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Columns | Field names. |
| Data | The rows. |

### Browse

Shows the data flowing through a point in the workflow, with profiling and charts.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

**Notes:** Place it anywhere to inspect data without writing a file.

## Preparation

### Select

Keeps, drops, renames, reorders and re-types columns.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Fields | One row per column: keep, new name, data type. |
| *Unknown | A row that stands for columns not listed (for example new columns arriving later). Keep it checked to let them through. |

**Notes:** Columns not listed and without an *Unknown row are dropped.

### Auto Field

Chooses the smallest suitable data type for text columns that hold numbers, dates or booleans.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

### Filter

Splits records into those that match a condition (True) and those that do not (False).

- **Inputs:** `I` (Input)
- **Outputs:** `T` (True / Target), `F` (False)

| Setting | What it does |
|---|---|
| Mode | Basic (field / operator / value rows) or Custom (a formula expression). |
| Conditions | Combined with AND or OR. |

**Notes:** Both outputs can be used; unmatched records are never lost.

### Formula

Creates or updates columns using expressions (math, text, dates, IF/ELSE).

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Output field | New or existing column. |
| Expression | See FORMULA_REFERENCE.md. |
| Type | Result data type. |

**Notes:** Expressions use square brackets for fields, for example [Price] * [Qty].

### Multi-Row Formula

Calculates a value that depends on other rows, such as the previous record.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Output field | New or existing column. |
| Expression | Can refer to the row above or below. |
| Group by | Restart per group. |

### Multi-Field Formula

Applies one expression to many columns at once.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Fields | Which columns to change. |
| Expression | Use the placeholder for the current field. |
| Output | Update in place or create new columns with a prefix/suffix. |

### Sort

Orders records by one or more columns, ascending or descending.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Sort fields | Column and direction, in priority order. |
| Case sensitive | Whether upper and lower case sort separately. |

### Data Clean

Tidies text and missing values: trim spaces, change case, remove characters, replace nulls.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Columns | Which columns to clean. |
| Whitespace / characters | Trim, remove tabs and line breaks, letters, numbers, punctuation or custom text. |
| Case | Upper, lower or title case. |
| Nulls | Replace missing text or numbers with a value. |

### Unique

Splits records into the first of each key combination (Unique) and the repeats (Duplicate).

- **Inputs:** `I` (Input)
- **Outputs:** `U` (Unique), `D` (Duplicate)

| Setting | What it does |
|---|---|
| Columns | Key columns that define a duplicate. |

**Notes:** Both outputs are available.

### Sample

Keeps or skips records: the first or last N, every Nth, a random share, a percentage, or a range.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Sample type | First N, Last N, Skip first N, 1 in N, Random 1 in N, First N percent, or Records range (for example 10-15, -5, 20+). |
| N / percent / range | The number, percentage or range for the chosen type. |
| Group by | Apply the sample within each group. |
| Seed | Makes the random type repeatable. |

### Record ID

Adds a sequential number column.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Column name | Default RecordID. |
| Start value | First number. |
| Position | First or last column. |
| Group by | Restart numbering for each group. |

### Running Total

Adds a cumulative-sum column for each selected numeric field, optionally restarting per group.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Fields to total | Each gets a new column named RunTot_<field>. |
| Group by | Restart the total for each group. |

**Notes:** Records keep their original order. Non-numeric values count as 0.

### Dynamic Rename

Renames columns in bulk: use the first row as headers, or add a prefix or suffix to every column.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Mode | First row as headers, add prefix, or add suffix. |
| Prefix / suffix | Text to add. |

**Notes:** With first-row mode the first record becomes the header and is removed from the data.

## Join

### Join

Combines two inputs by matching key columns. Matches go to J; unmatched records to L and R.

- **Inputs:** `L` (Left), `R` (Right)
- **Outputs:** `J` (Joined), `L` (Left), `R` (Right)

| Setting | What it does |
|---|---|
| Join keys | Pair a left and a right column. |
| Ignore case | Match text without regard to case. |
| Select fields | Choose and rename the columns in the result. |

**Notes:** Duplicate keys on both sides produce every combination (as in Alteryx).

### Join Multiple

Joins three or more inputs on shared keys.

- **Inputs:** `I` (Input)
- **Outputs:** `J` (Joined)

| Setting | What it does |
|---|---|
| Join keys | Columns shared by all inputs. |
| Join mode | Specific fields or all fields. |

### Union

Stacks several inputs into one.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Mode | Match columns by name or by position. |
| Non-matching columns | Keep all columns (filling gaps with null) or only those common to every input. |

### Find Replace

Looks up values from a second table and replaces or appends matching data.

- **Inputs:** `F` (False), `R` (Right)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Find field | Column in the main input (F anchor). |
| Lookup field and value field | Columns in the reference input (R anchor). |
| Action | Replace the matched text, or append fields from the reference record. |
| Search mode | Match the entire field, the beginning of the field, or anywhere in it. |
| Case sensitive / whole word | Matching options. |

### Append Fields

Adds every column of a small second input (Source, S) to every record of the first (Target, T).

- **Inputs:** `T` (True / Target), `S` (Source)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Cartesian mode | Stop with an error (default), warn, or allow when the Source has more than 16 records. |
| Source prefix | Added to Source columns whose names clash with Target columns. |

**Notes:** By default a Source with more than 16 records is refused, to prevent accidentally huge results.

## Transform

### Summarize

Groups records and calculates totals, averages, counts and similar.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Actions | For each column choose Group By or an aggregate: Sum, Average, Min, Max, Median, Std Dev, Variance, Product, Percentile, First, Last, Count, Count Distinct, Count Null / Non-Null / Blank / Non-Blank, Longest, Shortest, Concatenate (also distinct), and the financial functions NPV, XNPV, IRR, XIRR, MIRR. |

### Transpose

Turns selected columns into rows (unpivot).

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Key columns | Columns that stay as they are. |
| Data columns | Columns to turn into rows. |
| Name / value columns | Names of the two new columns. |

### Cross Tab

Turns row values into columns (pivot).

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Group by | Rows of the result. |
| Header field | Values that become column names. |
| Value field and method | What to aggregate and how. |

## AI

### LLM Process

Sends each record to a language model with your prompt and stores the answer.

- **Inputs:** `I` (Input)
- **Outputs:** `O` (Output)

| Setting | What it does |
|---|---|
| Provider and model | Ollama, LM Studio, OpenAI, Azure OpenAI, Gemini or any OpenAI-compatible endpoint. |
| Prompt template | Use {{column}} to insert values from each record. |
| Output mode | Single column, JSON fields, or structured output. |
| Concurrency and retries | Throughput and error handling. |

**Notes:** Row values are sent to the configured endpoint. Local endpoints send nothing off your PC; any other host must be approved once. API keys are stored in Windows Credential Manager.

### Schema Fit

Reshapes a source table to match a target table's columns and types, showing the steps it took.

- **Inputs:** `M` (Model), `T` (True / Target), `S` (Source)
- **Outputs:** `T` (True / Target), `D` (Duplicate)

| Setting | What it does |
|---|---|
| Max transformations | Number of correction attempts when using a model. |
| Only target columns | Drop columns that are not in the target. |
| Custom code | Provide your own pandas steps instead of a model. |

**Notes:** Generated code runs in an isolated, restricted process with a time and memory limit. Without a model it uses a built-in matcher. Sample values are sent to a remote model only after you approve the host.

### LLM Override

Defines a model connection once and passes it to AI tools through the M anchor.

- **Inputs:** none
- **Outputs:** `M` (Model)

| Setting | What it does |
|---|---|
| Provider, model, endpoint, API key | Connection details. |

**Notes:** The key is stored securely and is never saved in the workflow file.
